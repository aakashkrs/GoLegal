Select Your State to File Grievance

Instructions:

  1. Select your state from the dropdown list.
  2. Your browser will open a new tab with the official website of your state's grievance portal.
  3. Follow the instructions on the state website to file your grievance.
  4. If you encounter any issues, please contact the state support for assistance.
  5. Ensure that you have the necessary documents and information ready before submitting your grievance.
